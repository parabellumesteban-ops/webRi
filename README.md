## Getting started

> **Prerequisites:**
> The following steps require [NodeJS](https://nodejs.org/en/) to be installed on your system.

Install dependencies:

```
npm install
```

Run UI + contact API together:

```
npm run dev
```

- Frontend: [http://localhost:5173/](http://localhost:5173/)
- Contact API health: [http://localhost:8787/api/health](http://localhost:8787/api/health)

Build for release:

```
npm run build
```

## Contact backend

In production the contact form posts to Formspree (`VITE_CONTACT_ENDPOINT` in `.env.production`). When that variable is not set it uses the optional Express backend:

- `POST /api/contact`

In development, Vite proxies `/api/*` to `http://localhost:8787`.

Leads are stored locally in:

- `server/data/contact-leads.ndjson`

Optional env vars:

- `CONTACT_API_PORT` (default: `8787`)
- `CONTACT_WEBHOOK_URL` (optional webhook for forwarding each lead)
- `VITE_API_BASE_URL` (optional frontend override for API base URL)
- `VITE_SITE_URL` (public origin for canonical/Open Graph URLs)
- `TRUST_PROXY` (proxies trusted for `X-Forwarded-For`, default `loopback`)

Tests (Node >= 22.18):

```
npm test
```
